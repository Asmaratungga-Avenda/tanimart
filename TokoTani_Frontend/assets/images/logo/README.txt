LETAKKAN LOGO TANIMART DI SINI

  tanimart_logo.png   -> logo lengkap (emblem + tulisan TaniMart). Dipakai di Splash & Login. Disarankan PNG transparan, lebar >= 600 px.
  tanimart_icon.png   -> ikon persegi (emblem saja). Dipakai di header Beranda. Disarankan 256x256 px.

Jika berkas belum ada, aplikasi otomatis memakai logo gambar-tema (ikon daun hijau) sehingga tidak error.
Setelah mengganti berkas jalankan: flutter pub get && flutter run
