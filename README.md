# TokoTani

Repository ini berisi dua aplikasi yang dikelola terpisah:

- `TokoTani_Backend/` — API berbasis Laravel.
- `TokoTani_Frontend/` — aplikasi Flutter.

## Frontend

Jalankan perintah berikut dari folder frontend:

```shell
cd TokoTani_Frontend
flutter pub get
flutter test
flutter run
```

## Backend

Ikuti petunjuk instalasi dan konfigurasi Laravel di `TokoTani_Backend/README.md`.
